# 코드 설명

## 1. 전체 흐름

```
COCO train2017 (118,287장)
   │  p1: 20개 부분집합으로 균등 분할 (seed 42, 부분집합당 약 5,915장)
   ▼
D1 (subset_01)  ──► 초기 레이블러 L0 학습 (YOLOv8s scratch)
D2 (subset_02)  ──► 보정용 데이터셋 Dc: 클래스별 임계값 산정에만 사용 (학습에 안 씀)
D3~D20          ──► 라운드 1~18의 비레이블 데이터 U1~U18

라운드 r (r = 1..18):
  1) 레이블러 L(r-1)로 U_r 예측
  2) 클래스별 임계값 t_c 이상인 예측만 의사 레이블로 채택
  3) D1 정답 + 최근 3라운드 의사 레이블로 L(r-1)에서 이어서 12 에포크 재학습 → L_r
  4) L_r을 val2017에서 평가 (정밀도·재현율 conf 0.25, mAP@0.5:0.95)
  5) 실험 C: r이 3의 배수이면 L_r로 Dc를 다시 추론해 t_c를 다시 산정
  6) val mAP가 직전 라운드보다 3라운드 연속 떨어지면 종료
```

## 2. 파일별 역할

| 파일 | 역할 |
|---|---|
| `src/p1_data_slicing_and_initial_learning.py` | COCO 분할(`subsets/subset_01~20.json`), YOLO 형식 변환, 초기 레이블러 학습, 부분집합·val2017 평가. 결과는 `<out-dir>/p1_output/` |
| `src/p0_common_api.py` | 공통 함수와 **모든 설정값**. 평가(IoU 매칭, AP 101점 보간), 클래스별 임계값 산정, 누적 학습 데이터셋 구성, 재학습, 라운드 조기 종료, 결과 저장 |
| `src/p2_1_fixedthr_ext.py` | 실험 A: 모든 클래스에 `--fixed-conf` 값 하나를 고정해 18라운드 수행. 결과는 `<out-dir>/<run-name>/` |
| `src/p2_2_pseudo_label_ext.py` | 실험 B·C: Dc에서 클래스별 임계값을 산정해 18라운드 수행. `recalib_every_n_rounds`가 None이면 고정(B), 3이면 3라운드마다 갱신(C). 결과는 `<out-dir>/p2_2_output/` |

p2 두 파일은 `<out-dir>/p1_output/`(부분집합 JSON과 `weights/labeler_best.pt`)을 읽기만 합니다.

## 3. 핵심 함수

| 함수 | 위치 | 하는 일 |
|---|---|---|
| `derive_class_thresholds` | p0 | Dc 예측을 클래스별로 신뢰도 내림차순 정렬해, 누적 정밀도가 `target_precision`(0.6) 이상인 가장 낮은 신뢰도를 임계값으로 정함. GT가 20개 미만이거나 0.6에 못 미치면 `fallback_conf`(0.4). 마지막에 `[min_conf_thr, max_conf_thr]`로 자름 |
| `setup_class_thresholds` | p2_2 | Dc를 추론해 `derive_class_thresholds`를 부르고 `pseudo_class_thresholds.csv`로 저장 |
| `process_round_subset` | p2_1, p2_2 | U_r을 예측하고 임계값 이상 박스를 의사 레이블로 선택. 채택 라벨의 정확도(U_r 정답 대비)도 기록 |
| `append_pseudo_round` / `prune_pseudo_round` | p0 | 의사 레이블을 누적 학습셋에 추가하고, 3라운드보다 오래된 것은 제거(슬라이딩 윈도우) |
| `retrain_labeler` | p0 | 직전 라운드 가중치에서 이어서 재학습 (Ultralytics `train`) |
| `update_best_checkpoint` | p0 | 최고 라운드 기록과 라운드 조기 종료 판정 (직전 라운드 대비 연속 하락 수) |
| `run_round` | p2_1, p2_2 | 위 단계를 묶은 라운드 1회 |

## 4. 설정값 (`src/p0_common_api.py`)

### 임계값 산정 (`get_selection_config`)

| 키 | 값 | 의미 |
|---|---|---|
| `target_precision` | 0.6 | 클래스별 임계값을 정하는 Dc 목표 정밀도 |
| `min_gt_per_class` | 20 | Dc GT가 이보다 적은 클래스는 산정하지 않고 fallback 사용 |
| `fallback_conf` | 0.4 | 산정 불가 클래스의 임계값 (fork, toaster, hair drier, toothbrush 4개) |
| `min_conf_thr` / `max_conf_thr` | 실험마다 다름 | 범위. 범위 없음은 0.00 / 1.00 |
| `recalib_every_n_rounds` | 실험마다 다름 | None = 고정(B), 3 = 3라운드마다 갱신(C) |

### 학습 (`get_retrain_config`, 초기 학습은 p1의 학습 설정)

| 항목 | 초기 레이블러 (p1) | 라운드 재학습 (p0) |
|---|---|---|
| 모델 | yolov8s.yaml (scratch) | 직전 라운드 가중치 |
| epochs / patience | 200 / 25 (실제 196 에포크) | 12 / 6 |
| optimizer | SGD, momentum 0.937, weight_decay 0.0005 | 같음 |
| lr0 / lrf | 0.01 / 0.01 | 0.002 / 0.01 |
| batch / imgsz | 16 / 640 | 16 / 640 |
| 증강 | mosaic 1.0, copy_paste 0.2, mixup 0.15 | 같음, close_mosaic 3, warmup_epochs 1 |
| 검증 데이터 | val2017 | val2017 (에포크 조기 종료와 best.pt 선택에 쓰임) |

옵티마이저를 `auto`가 아닌 SGD로 고정한 이유: Ultralytics `auto`는 학습 반복 수에 따라 SGD와 AdamW, 학습률을 자동으로 바꾸므로 실험·라운드마다 학습 조건이 달라집니다.

### 라운드

| 키 | 값 | 의미 |
|---|---|---|
| `max_pseudo_rounds_kept` | 3 | 최근 3라운드 의사 레이블만 학습에 사용 |
| `round_early_stop_patience` | 3 | val mAP가 직전 라운드보다 3라운드 연속 떨어지면 종료 |

## 5. 평가 지표

- mAP@0.5:0.95: conf ≥ 0.001 예측, COCO 101점 보간, IoU 0.5:0.05:0.95
- 정밀도·재현율·TP·FP: conf ≥ 0.25, IoU ≥ 0.5, 같은 클래스 GT와 신뢰도 순 1:1 greedy 매칭
- iscrowd GT와 겹치는 미매칭 예측은 무시하고, iscrowd GT는 GT 수에서 제외
- ρ_P, ρ_R: 마지막 라운드 값 / 1라운드 값. ρ_P < 0.9이고 마지막 mAP < 최고 mAP면 정밀도 붕괴

## 6. 출력 파일 (`p2_*_output/`)

| 파일 | 내용 |
|---|---|
| `pseudo_round_results.csv` | 라운드별 val2017 지표(`val_Precision`, `val_Recall`, `val_mAP@0.5:0.95` 등)와 채택 의사 레이블 통계 |
| `pseudo_round_class_metrics.csv` | 라운드별·클래스별 val2017 GT, TP, FP, FN, AP |
| `pseudo_class_thresholds.csv` | 마지막으로 쓴 클래스별 임계값 (`used_fallback` 표시) |
| `pseudo_class_thresholds_roundXX.csv` | 라운드 XX에 산정한 임계값 (00 = 최초, 갱신 실험은 03, 06, …) |
| `pseudo/runs/pseudo_round_XX/weights/best.pt` | 라운드별 가중치 (results/에는 포함하지 않음) |

## 7. 중단된 실험 이어 돌리기

p2 두 파일은 `--resume-dir <상태 폴더> --start-round <r>`로 r라운드부터 이어서 실행할 수 있습니다. 상태 폴더 구성:

```
resume_state/
├── pseudo_round_results.csv, pseudo_round_class_metrics.csv, pseudo_class_thresholds.csv
├── weights/round_01_best.pt … round_(r-1)_best.pt
└── yolo_data/manifests/round_(r-2).json, round_(r-1).json  + yolo_data/labels/train/*.txt
```

`--dry-run`을 붙이면 복원까지만 하고 학습 없이 끝나므로, 복원 로그를 먼저 확인할 수 있습니다.
