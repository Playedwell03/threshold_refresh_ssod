# 결과 재현

논문의 표·그림을 다시 얻는 방법과, 각 실험에서 나와야 할 값입니다. 모든 명령은 저장소 최상위에서 실행합니다.

## 1. 준비

```bash
bash scripts/run_initial.sh /path/to/coco
```

COCO train2017을 20개 부분집합으로 나누고(seed 42) 부분집합 1로 초기 레이블러를 학습합니다. 모든 실험이 이 결과(`runs/base/p1_output/`)를 함께 씁니다.

| 항목 | 기대값 (`results/initial_labeler/`) |
|---|---|
| 학습 에포크 | 최대 200, 196 에포크에서 조기 종료 |
| 최고 val mAP@0.5:0.95 | 0.1994 |

## 2. 실험별 실행과 기대값

```bash
bash scripts/run_experiment.sh <실험이름> /path/to/coco
```

기대값은 `results/<실험이름>/pseudo_round_results.csv`에서 계산한 값입니다. ρ_P는 마지막 라운드 정밀도 ÷ 1라운드 정밀도이고, 0.9 미만이면서 마지막 mAP가 최고 mAP보다 낮으면 정밀도 붕괴입니다.

## 3. 표·그림 생성

```bash
python scripts/make_tables_figures.py --results results --out paper_outputs
```

`results/` 대신 직접 돌린 결과로 만들려면, 각 실험의 `runs/<실험이름>/p2_*_output/*.csv`를 `results/<실험이름>/`과 같은 구조의 폴더에 모은 뒤 `--results`로 그 폴더를 넘깁니다.

## 4. 참고

- **재현성:** 같은 장비에서는 같은 설정이 소수점까지 같은 결과를 냅니다. Ultralytics 8.4.51이 데이터로더 시드를 고정하므로 `seed`를 바꿔도 결과가 같습니다. GPU가 다른 장비에서는 라운드별 mAP가 0.003 정도 다를 수 있습니다.
- **이어서 실행:** 일부 실험은 중간에 멈춘 뒤 `--resume-dir`, `--start-round`로 이어서 실행했습니다. 이어서 실행해도 최고 라운드와 연속 하락 수가 복원되므로 한 번에 실행한 것과 같은 규칙을 따릅니다(방법은 `docs/코드_설명.md` 7절).
- **추가 실험:** `results/extra_C_refresh_0.3-0.6`(갱신, 범위 0.3~0.6, 최고 mAP 0.2131)과 `results/extra_C_init0.4_norange`(1~3라운드는 모든 클래스 0.4, 이후 범위 없는 갱신, 최고 mAP 0.2086)는 논문에 넣지 않은 결과입니다. 후자는 `src/`에 없는 설정으로 수행해 `run_experiment.sh`로는 재현되지 않습니다.
